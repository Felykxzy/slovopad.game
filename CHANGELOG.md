# CHANGELOG

## [1.3.2] - 2026-11-05

### 🔊 Аудио и Звуки (Web Audio API)
- **Динамический питч при печати:** Каждая следующая правильно введенная буква в слове звучит с повышением тональности (`soundManager.playKeypress()`).
- **Сочный звук завершения:** Автоматический проигрыш арпеджио-аккорда при полном наборе слова (`soundManager.playWordComplete()`).
- **Звуковые эффекты событий:** Добавлен звук ошибки при неверной клавише (`soundManager.playError()`) и низкий басовый гул при наведении/ударе слова о щит (`soundManager.playDamage()`).
- **Авто-разблокировка на iOS:** Реализовано снятие ограничений Safari/iOS на автовоспроизведение звуков при первом касании экрана.

### 📱 Поддержка iOS & PWA
- **Полная интеграция Web Audio:** Звуковой модуль выделен в отдельный файл `audio.js` и оптимизирован для `WKWebView` и PWA.
- **Подготовка под нативную упаковку:** Код адаптирован для бесшовного оборачивания через Capacitor / Xcode.
